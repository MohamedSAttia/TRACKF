| `assets/` | | الشعار والصور ورمز QR |

## النشر على Vercel
1. ارفع محتوى هذا المجلد إلى مستودع GitHub.
2. Vercel → Add New → Project → اختر المستودع → Deploy (بدون إعدادات بناء).
3. لتفعيل الذكاء الاصطناعي: Settings → Environment Variables → `ANTHROPIC_API_KEY` ثم Redeploy.
   (اختياري) `ANTHROPIC_MODEL` — الافتراضي `claude-sonnet-5`.

بدون المفتاح تعمل كل الوحدات؛ ويعمل مساعد الأكاديمية من قاعدة معرفته الداخلية، ويعرض المقيّم توصيات محسوبة.
البيانات تُحفظ في متصفح المستخدم فقط.
